# Whitewater-png Meltype-for-mac

## How do I install these formulae?

`brew install whitewater-png/meltype-for-mac/<formula>`

Or `brew tap whitewater-png/meltype-for-mac` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "whitewater-png/meltype-for-mac"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
